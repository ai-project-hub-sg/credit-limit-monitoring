# Credit Limit Monitoring

Credit Limit Monitoring 是一个面向 Pixel OpenAI 账号管理员的本地 Web 监控工具。它周期性采集账号的 `seven_day` 用量，保存原始响应和历史指标，在额度估算异常时发送邮件，并可按策略暂停异常账号的 Pixel 调度。

> 当前状态：项目仍处于需求评审阶段，当前基线为 [PRD 1.4-draft](docs/PRD.md)。仓库尚无可运行程序、安装包、依赖清单或启动命令。本文介绍计划交付的产品形态，不能当作已经实现的功能说明。

## 主要能力

- 同时接入多个 Pixel 租户，并支持每个租户配置多个管理账号。
- 只监控 Pixel 中 `platform=openai` 的账号。
- 默认每 60 秒采集一次用量；异常观察期间可切换到默认 30 秒，两个间隔均计划支持配置。
- 保存完整原始 JSON，并把结构化采样、指标、告警、邮件和调度动作写入加密 SQLite 数据库。
- 展示两项稳定额度指标和两项实时观察指标；稳定指标用于告警判断，实时指标用于观察。
- 支持多套命名阈值预设、全局与账号级继承、筛选和原子批量修改。
- 稳定 delta 低于生效最低阈值时，可按全局和账号策略自动暂停 Pixel 调度。
- 同一账号同一次采样命中的已启用提醒，最多合并发送一封邮件；各规则结果仍分别保留审计记录。
- 支持两个独立根密钥：数据库口令和机密信息加密密钥，并支持分别查看与轮换。

详细指标公式、异常矩阵和验收条件请以 [产品需求文档](docs/PRD.md) 为准。

## 计划交付形态

### Windows 首版

- 交付单个可直接点击运行的 `.exe`。
- 首次运行时，在可执行文件同目录创建 `.env` 和加密数据库。
- 后续业务配置通过 Web 页面保存到数据库。

### Linux 版

- 面向 64 位 x86_64 Linux，交付单个应用可执行文件。
- `.env` 和加密数据库同样放在程序文件同目录。
- 使用操作系统服务管理开机启动和异常退出后的拉起，由 Nginx 提供反向代理和外部 TLS。
- 具体发行版和版本只决定最终封包基线及系统运行库兼容性验证，不阻塞前期产品和通用功能开发。

## 快速上手流程（发布后）

1. 把应用可执行文件放入一个仅受信任管理员和运行账号可访问、且运行账号可写的目录。
2. 首次启动应用，确认同目录成功生成 `.env` 和加密数据库；不要把 `.env` 提交到 Git 或发送到日志。
3. 通过发布说明给出的 Web 地址登录。初始凭据为：

   ```text
   用户名：fuck_openai
   密码：pixel_test
   ```

4. 首次登录后立即按页面要求修改默认密码；在完成改密前不能进入正常业务页面。
5. 配置 Pixel 租户、管理账号、SMTP、通知人、采样间隔、阈值预设和自动暂停策略。
6. 同步 OpenAI 账号，选择需要监控的账号，并观察首次采样、指标预热和邮件测试结果。

当前仓库还没有发布包，因此以上流程是已确认的交付目标，而不是现在可执行的安装步骤。

## 备份与恢复

Windows 和 Linux 使用同一安全边界：

- `.env` 和加密数据库只能通过操作系统或服务器文件管理方式取得和备份。
- Web 不提供 `.env` 或数据库文件的下载、导出、备份与恢复入口。
- 完整恢复必须同时持有相互匹配的 `.env` 和加密数据库文件；缺少其中任一项都不能承诺恢复。
- 复制数据库前必须停止写入，或使用实现阶段验证过的一致性备份方式；直接复制正在写入的主文件可能遗漏 WAL 数据。
- 备份文件应限制访问权限并离线保管。文件复制、传输和跨机器恢复由部署管理员负责。

## 本地查看数据库

产品不提供 SSH 隧道、远程数据库端口或 DBX 远程连接。需要查看数据库时，应先通过操作系统取得一致性的加密数据库副本，再在本地使用经过验收的 DBX 或带 SQLCipher 支持的 DB Browser 打开。

数据库口令只能解开文件层。Pixel 凭据、Token 和 SMTP 密码等由第二个密钥保护的字段仍应保持密文。第三方客户端兼容目标和验证方法见 [架构文档](docs/ARCHITECTURE.md) 与 [测试计划](docs/TEST_PLAN.md)。

## 安全提示

- 不要公开默认部署目录中的 `.env`、数据库、原始响应或日志。
- 不要把 Token、Pixel 密码、SMTP 密码或根密钥写入示例、命令行参数或问题报告。
- 首次登录必须修改默认密码；密钥查看和轮换需要再次验证管理员密码。
- 自动暂停只影响 Pixel 调度，本地监控是否继续由本产品自己的监控配置决定。
