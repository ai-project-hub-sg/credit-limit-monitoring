## 1. 结论摘要

这是一个面向单机运维人员的 Pixel OpenAI 账号额度监控系统。系统通过 Pixel 的登录和账号接口定期读取 seven_day 用量，保存原始 JSON 和结构化采样，逐采样计算两个实时指标，并在有效 utilization 跳变时计算两个稳定额度指标。稳定 cost 与 delta 异常分别发送邮件，并按全局和账号级策略选择是否关闭账号调度。

当前仓库位于 Git `main` 分支，2026-09-28 检查时 HEAD 为 `c0dccc7 docs:确认了一些需求变更`；仓库仍没有业务代码、依赖清单、构建命令或 CI。本阶段只形成需求和设计文档，不能声称已有构建、运行或测试能力。

## 3. 用户与场景

主要用户是部署该工具的管理员或运维人员：

1. 首次登录并修改默认密码。
2. 配置多个 Pixel 租户、租户下管理账号、SMTP 和监控参数。
3. 查看账号用量、两项稳定指标、两项实时指标、趋势、delta 档位和原始记录。
4. 分别收到 cost 与 delta 异常邮件；策略允许时自动暂停 Pixel 调度，否则按提示人工处理。
5. 管理原始数据保留、缓存字节上限、密钥查看和独立轮换。

首版仍只有一个本地管理员角色；“多个租户”是上游连接能力，不是本地多人多组织权限。

## 4. 技术与复杂度判断

### 前端：中等

包含登录/改密、Pixel 连接、仪表盘、账号列表/详情、配置、通知、数据管理、安全设置和日志。需要维护状态、异常确认、密钥轮换维护态、加载/空/错误/无权限状态，以及账号级通知人和事件进度展示。低保真页面审核前不制作原型。

### 后端：中等偏高

包含多租户 Token、定时调度、原始文件队列、数据库 ETL、四指标与跳变锚点、进程重启预热、双事件邮件去重、调度 PUT、`.env` 原子轮换和缓存背压。单账号失败必须与其他账号隔离。

### 数据库：必须保留

需要按租户、管理账号、监控账号和时间查询采样，保存紧邻前值、跳变锚点、进程启动代次、cost/delta 独立事件、邮件和调度审计。SQLite 已确定；建议使用 SQLCipher 文件加密、事务和受控单写队列。具体绑定、Windows/Linux 包及 DBX 本地互操作要在实现阶段验证。

### 语言和运行时

本轮已撤销后端必须使用 Go 的限制，语言、框架与构建工具未选定。SQLCipher 提供 C/C++ 接口，使用它不要求 Go；推荐基线不重新引入 Go。实际绑定、原生库与打包需另行选择。[来源见架构 S1]

此前 `sqlite3-encrypted` 的来源仍未核实，无法断言其格式；如果实际是 SQLite3 Multiple Ciphers，则可配置 SQLCipher 兼容模式，但不能使用任意默认参数后保证 DBX 打开。[来源见架构 S3]

## 5. 关键风险

- README 已确认公式乘以 100 的量级，但跨多个百分点、回退/重置及重启后的基线重建仍需接受明确规则。
- 稳定指标、实时指标、加速观察计数是三套相关状态；如果实现混用锚点，可能重复告警或错误暂停。
- SQLCipher 默认格式与口令模式有官方依据，但实际驱动包、DBX 客户端版本、轮换后重开及跨平台备份互操作尚未实测。
- `.env` 允许无人值守启动，但根密钥以明文文件存在于应用根目录；操作系统权限、备份、轮换原子性和丢失后的恢复责任必须写清。
- 用户自行取得活动数据库文件时可能漏掉 WAL 或得到不一致副本；交付说明必须要求停写或使用一致性备份机制。
- usage 的 requests/tokens 字段、分页、Token 失效和暂停 PUT 成功响应需脱敏样例确认。
- 开发若直接复用关联项目 pipeline/store 的旧 `estimated_total_quota` 会产生错误口径；只能复用接口字段与认证经验，指标必须按本 PRD 重新实现。
- 原始缓存满且全部文件未抽取时不能删除待处理数据，需要明确背压和恢复行为。

## 6. 仍需确认与下一道审核门

`docs/PRD.md` 第 11 节 R1–R3 是当前需要用户定稿的三组问题：

- R1：是否接受只把恰好 +1 视为有效跳变、异常变化重建基线，以及跳变当条实时 delta 按新锚点归零。
- R2：`.env` 是否完全由用户随数据库安全备份，产品不提供 Web 下载，以及 Windows/Linux 文件权限边界。
- R3：Windows/Linux 的语言、包形态、CPU、服务账号和部署目录；SSH/远程数据库功能已经明确排除。

此外需补齐脱敏 usage、分页账号列表、认证失败和暂停 PUT 响应样例。确认后才能进入低保真页面和技术实现设计；在确认前不创建原型、后端、前端、迁移或安装包。
